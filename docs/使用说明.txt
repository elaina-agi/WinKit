WinKit 0.1.1 — Windows 工具箱
=========================

系统：Windows 10/11 x64。
启动：双击 WinKit.exe，无需安装 .NET。

NUL 清理
--------
1. 在输入框输入/粘贴要检查的文件夹，或点击“浏览…”选择。
2. 点击“开始扫描”。工具会递归扫描，但不会跟随符号链接或目录联接。
3. 检查完整路径。默认没有勾选；可以逐项选择或全选。
4. 点击“删除所选”，确认永久删除。
5. 查看逐项处理状态；权限不足、占用、只读等失败不会自动提权或改属性。

主题切换
--------
点击窗口右上角“切换夜间 / 切换浅色”，或在设置里勾选“夜间主题”。
切换立即生效，会记住选择；不重新扫描，不改变已有文件勾选。
标题栏在支持的 Windows 上跟随主题；系统文件夹选择和删除确认框外观由 Windows 决定。

注意
----
- 仅处理文件名精确为 nul 的普通文件，不区分大小写。
- 不处理 null、nul.txt、名为 nul 的文件夹或其他保留名称。
- 删除不经过回收站，不能依靠本工具撤销。
- 扫描中有无权限目录等问题，会提示不完整；不要把它理解为全部检查成功。
- 扫描后文件或所选目录被替换时，会拒绝删除；请重新扫描。
- 将扫描范围设为具体的项目文件夹比扫描整个系统磁盘更合适。
- 单文件自包含版本首次启动可能需要解压运行时组件到本地缓存。
- 本版本未做代码签名，Windows 可能提示未知发布者。

配置与操作记录存放于当前用户的本地应用数据目录，可通过界面查看。
工具默认普通用户权限运行，不进行后台自动扫描或自动删除。
