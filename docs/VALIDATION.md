# 验证说明

所有创建/删除测试数据仅发生于测试自己创建的唯一临时目录，禁止用用户已有问题文件进行验证。

## 核心回归

```powershell
.\scripts\test.ps1
```

测试可执行程序直接调用原生文件接口创建真实的 Windows 保留名对象，不依赖 shell 的 `> nul` 行为。失败返回非零退出码。覆盖项与跳过原因见 [`核心测试说明`](../tests/WinKit.Core.Tests/README.md)。

## 真实桌面交互

先发布，再运行：

```powershell
.\scripts\publish.ps1
.\scripts\test-desktop.ps1
```

独立 UI Automation 测试启动发布后的 EXE，使用 `--test-data-directory` 将设置和日志隔离至临时目录，不触碰当前用户的实际设置。

检查路径输入、无效路径、系统文件夹选择对话框及取消保留原路径、扫描默认不选、全选与取消全选、真实系统确认框（默认为否）、取消删除保留文件、单项删除只影响所选对象（两个候选为同一文件的不同硬链接，专门检查按路径匹配结果）、随后删除剩余项、普通文件及 `nul` 目录不受影响、页面导航和正常关闭。测试保留其小型唯一临时目录作为证据。

此测试需要可交互 Windows 桌面；不要在没有 GUI 会话的 CI 服务中假装它已执行成功。

## 本机实际验证结果

Windows 11 x64，SDK 10.0.404，Release：

- 全解决方案构建：**0 警告、0 错误**。
- 核心：**25 通过、1 跳过、0 失败（共 26 项）**。唯一跳过为文件符号链接创建，Windows 错误 1314；目录联接和大小写敏感目录测试确实执行通过。
- 发布的自包含 EXE：**22 个桌面断言通过**，包含系统文件夹选择和实际永久删除确认。
- 扫描截图验证：**Passed=true**，默认勾选数 0，全选后 2，取消全选后 0；**0 个数据绑定错误**。默认及最小窗口尺寸、操作记录与设置页布局已检查。

真实网络共享和文件符号链接分支未在本机完成实测，不能据此承诺全平台或全部文件系统都已覆盖。

## 真实 WPF 渲染

```powershell
.\scripts\test-ui-smoke.ps1 -FixtureDirectory <自己创建的测试目录> -OutputDirectory <截图输出目录>
```

这个入口只扫描，不执行删除。输出扫描状态 JSON、数据绑定错误和真实 WPF 窗口截图，包括最小窗口尺寸、操作记录、设置页。渲染截图与真实确认框的自动化测试分开，不以截图代替删除安全测试。

## 已知边界

- 当前只发布 Windows x64，不承诺 ARM64 或旧 Windows 的兼容性。
- 自包含程序未代码签名，可能显示未知发布者警告。
- 工具不强制解除占用、不自动提权、不更改只读属性。
- UNC 支持需远端文件系统支持所需的 Windows 原生文件信息/操作接口；不支持时拒绝操作并报告原因，不降级为不安全删除。
